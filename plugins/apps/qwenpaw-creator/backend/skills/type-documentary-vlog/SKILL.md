# 纪实/Vlog · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：真实、沉浸、生活感、亲切
- **叙事结构偏好**：松散随性，无严格结构。按时间/地点/主题自然串联。
- **节奏特征**：松散、随性、真实节奏。允许无意义的日常片段。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
真实感优先。手持拍摄的自然感。不过度构图。环境音比画质重要。

### 2.2 场景设计侧重
真实场景，不做布置。生活中的偶然发现是最有价值的内容。

### 2.3 分镜图侧重
中景(50%)日常，特写(30%)细节/食物/手，全景(20%)环境/风景。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
手持跟拍、自然光、环境音。第一人称视角增加沉浸感。

### 3.2 叙事节奏模板
真实节奏，不刻意加速或减速。有趣的片段自然停留更久。

### 3.3 声音设计方向
环境音是核心（街道/自然/人群）。旁白口语化、亲切。配乐轻松不抢戏。

## 4. 分镜表手法

### 4.1 镜头衔接规则
硬切为主。跳切用于时间压缩。叠化用于地点转换。

### 4.2 节奏控制技巧
真实感比完美感更重要。不完美的画面（抖动/过曝）是Vlog的特色。旁白像和朋友聊天。

### 4.3 情绪表达手法
根据真实、沉浸、生活感、亲切的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
