# 品牌宣传 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：高端、信任、向往、专业
- **叙事结构偏好**：问题/痛点 → 品牌出场 → 方案展示 → 效果证明 → CTA收尾
- **节奏特征**：精致优雅，每个镜头都经过设计。节奏稳重不急迫。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
精致运镜、品牌色、大字幕。画面品质代表品牌品质。

### 2.2 场景设计侧重
精心布置的场景。品牌元素自然融入。光线精致均匀。

### 2.3 分镜图侧重
中景(40%)展示，特写(30%)品质细节，全景(30%)环境/规模。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
精致运镜（稳定器/轨道/升降）。品牌色贯穿。构图严谨。

### 3.2 叙事节奏模板
稳重优雅。每个镜头给足时间展示品质。不 rushed。

### 3.3 声音设计方向
精致配乐（企业感/科技感/温暖感）。旁白专业有力。音效精致不夸张。

## 4. 分镜表手法

### 4.1 镜头衔接规则
平滑过渡为主。品牌色叠化。图形转场配合品牌元素。

### 4.2 节奏控制技巧
品牌片的核心是建立信任。画面品质=品牌品质。CTA要明确但不强硬。

### 4.3 情绪表达手法
根据高端、信任、向往、专业的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
