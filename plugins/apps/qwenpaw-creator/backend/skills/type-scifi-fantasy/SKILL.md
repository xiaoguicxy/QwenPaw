# 科幻奇幻 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：宏大、未知、震撼、敬畏
- **叙事结构偏好**：世界观建立 → 角色引入 → 冲突/探索 → 高潮对抗/发现 → 新世界/新平衡
- **节奏特征**：宏大舒展，允许长时间的世界观建立镜头。战斗/高潮段节奏加快。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
大远景展示宏大，CG全景展示奇观。注重 scale 感（人在巨大物体前的渺小）。

### 2.2 场景设计侧重
异世界/未来城市/太空/魔法场景。注重 scale 和细节的平衡。

### 2.3 分镜图侧重
全景(40%)建立宏大，中景(30%)叙事，特写(30%)角色反应。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
大远景、CG全景、史诗构图。缓慢升降展示 scale。环绕用于关键物体。

### 3.2 叙事节奏模板
世界观建立段落舒缓。冲突段落加快。高潮段落最宏大。

### 3.3 声音设计方向
宏大配乐（管弦/电子/合唱）。环境音构建异世界。科技音效/魔法音效。

## 4. 分镜表手法

### 4.1 镜头衔接规则
叠化用于时间/空间跳跃。硬切用于战斗。光效转场用于传送/魔法。

### 4.2 节奏控制技巧
Scale感是科幻奇幻的灵魂。每个新场景都要让观众wow。世界观通过细节暗示而非旁白灌输。

### 4.3 情绪表达手法
根据宏大、未知、震撼、敬畏的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
