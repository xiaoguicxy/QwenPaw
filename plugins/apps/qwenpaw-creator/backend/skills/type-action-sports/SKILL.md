# 动作运动 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：速度感、力量感、燃、肾上腺素
- **叙事结构偏好**：蓄势待发 → 爆发启动 → 高潮动作 → 关键瞬间 → 收尾定格
- **节奏特征**：快速剪辑，节奏爆发。平均2-4秒/Element。关键瞬间可慢动作延长。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
动态模糊控制、运动主体轮廓清晰度、画面信息密度优先。

### 2.2 场景设计侧重
运动场地/环境。注重空间感展示运动轨迹。光线服务于动态捕捉。

### 2.3 分镜图侧重
中景(40%)展示动作，特写(30%)表情/细节，全景(30%)空间/环境。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
跟拍、慢动作、广角动态。手持增加临场感。FPV穿越机用于极限运动。

### 3.2 叙事节奏模板
快节奏为主，关键瞬间用慢动作制造对比。节奏跟随运动本身。

### 3.3 声音设计方向
动作音效是核心（击打/落地/风声）。配乐高能量。环境音服务于临场感。

## 4. 分镜表手法

### 4.1 镜头衔接规则
硬切为主，配合动作节拍。甩镜用于场景切换。速度渐变（快→慢→快）。

### 4.2 节奏控制技巧
慢动作不超过总时长的20%。动作连贯性比画面完美更重要。

### 4.3 情绪表达手法
根据速度感、力量感、燃、肾上腺素的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
