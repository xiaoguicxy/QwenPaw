# Pixar/迪士尼 3D · 视觉风格

## 1. 风格定义

- **世界观/美学基调**：顶级3D动画工作室品质，角色表情丰富、材质真实、光影精致。情感表达细腻，适合全年龄段。
- **核心视觉特征**：圆润造型, 次表面散射, 柔和阴影, 饱和色彩, 精致材质
- **参考作品**：《玩具总动员》《寻梦环游记》《疯狂动物城》（皮克斯/迪士尼）

## 2. 严禁内容

以下元素与本风格冲突，不得在 prompt 中使用：
- 2D平面风格
- 低多边形
- 写实人脸（恐怖谷）
- 暗黑恐怖风格

## 3. 图片 Prompt 规范

### 3.1 风格前缀锚点（5-10 词）
所有图片 prompt 共享的风格方向（适配不照搬）：
`圆润造型, 次表面散射, 柔和阴影, Pixar/迪士尼 3D aesthetic`

### 3.2 色彩体系
饱和但和谐的色彩。角色用温暖色调，环境丰富但不过度。每个场景有明确的色彩脚本。

### 3.3 光照体系
精致的全局光照。次表面散射让皮肤半透明。柔和阴影，无硬边。环境光遮蔽增加深度。

### 3.4 角色设计 prompt 规范
圆润可爱造型，大眼睛（但不日式）。皮肤有次表面散射。服装材质真实。表情丰富细腻。

### 3.5 场景设计 prompt 规范
精致的3D环境，材质丰富。每个物件都有细节。光影营造氛围。

### 3.6 分镜图 prompt 规范
- 分镜图使用本风格的色彩和光照基准
- 画质限定词与风格匹配
- 相邻宫格保持风格一致

## 4. 视频 Prompt 规范

### 4.1 视频风格锚点（1-2 句）
Pixar/迪士尼3D动画品质，圆润造型，精致材质，柔和光影，饱和色彩。

### 4.2 运镜偏好
电影级运镜但保持动画的活泼感。特写捕捉微妙表情。全景展示精致环境。

### 4.3 色彩/光影方向
与图片保持一致的色彩体系和光照方向。视频中光影可以随叙事变化，但风格基调不变。

## 5. 完整 Prompt 示例

### 5.1 角色/场景设计图 prompt 示例
```
Medium shot, Pixar-style 3D animation. A cheerful girl with curly red hair, freckles, big green eyes, yellow raincoat and tiny boots, kneels in a puddle looking at a tiny glowing frog. Soft subsurface scattering, lush garden bokeh. Warm golden hour, rich materials. 16:9.
```

### 5.2 视频 prompt 示例
```
Shot 1 (wide, gentle dolly-in, 3s):
Pixar-style 3D. A cozy kitchen. A small robot with rounded body, big blue LED eyes, tiny wheels, rolls across the counter carrying a thimble watering can.

Shot 2 (close-up, static, 2s):
The robot tilts its head, eyes shifting from squares to hearts. It waters a tiny sprout. Soft warm window light.

Style: Pixar-quality 3D, rounded shapes, subsurface scattering, soft shadows, warm lighting.
Audio: Tiny motor whir, water drops, cheerful chirp.
```
