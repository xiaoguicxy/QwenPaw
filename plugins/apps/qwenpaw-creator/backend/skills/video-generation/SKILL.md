# 视频生成专项最佳实践

本 skill 指导如何高质量地编写视频 prompt、设计运镜、维护视觉连续性。

## 1. 视频 Prompt 结构化写法

### 1.1 五要素骨架应用

每个视频 prompt 必须填满五要素（详见 visual-prompt-foundations）：

```
[Subject]        主体类型 + 关键视觉属性 + 区分方式
[Subject Motion] 时间顺序的动作；主体间互动
[Scene]          场景叠加 + POV + 设定 + 时间 + 动态
[Spatial]        景别 + 画面位置 + 景深 + 机位高度 + 如何变化
[Camera]         回放速度 → 镜头畸变 → 高度 → 角度 → 焦点 → 稳定度 → 运动
```

### 1.2 时间戳分段与分镜格对应

video Prompt 必须以**时间戳分段**形式，将每个 Storyboard 格映射到视频的对应时间段：

- 每段开头明确标注对应的分镜格位置（如"对应分镜图左上格"）
- 时间戳秒数分配基于 Shot 的 `duration_seconds`
- 与分镜格顺序一一对应，不引入分镜表中不存在的阶段
- 每段 Prompt 以关键信息密度优先，不超过 200 词

### 1.3 对话表演 prompt 写法

当 Shot 包含 dialogue 时，需细化完整的对话表演说明：

**根据角色类型调整**：
- 人类角色：正常语气、肢体语言、面部表情
- 动画动物角色：保留动物特征（猫慵懒拖长音、狗兴奋语速快）
- 动画物体角色：语气符合物体材质（金属声、电子音）
- 真实动物：不适用台词，改用声音设计描述

**表演说明包含**：
- 语气（音量/语速/情感维度）
- 说话时的肢体语言
- 说话时的面部表情变化（台词前/说话中/说完后）
- 对话节奏（停顿、犹豫、加速）

**多角色对话**需明确交互节奏：谁先说、间隔多长、对方如何反应。

## 2. 运镜设计

### 2.1 基础运镜

| 运镜 | 效果 | 使用场景 |
|------|------|---------|
| 推镜头 (dolly in) | 逐渐靠近主体，增加亲密感/紧张感 | 情绪升级、聚焦细节 |
| 拉镜头 (dolly out) | 逐渐远离，揭示环境/孤独感 | 场景建立、结尾拉远 |
| 左/右摇 (pan) | 水平扫描环境 | 环境展示、跟随运动 |
| 上/下摇 (tilt) | 垂直扫描 | 展示高度、揭示全身 |
| 跟随 (tracking) | 跟随主体运动 | 动作场景、行走 |
| 固定 (static) | 零运动 | 静态构图、观察视角 |

### 2.2 高级运镜

| 运镜 | 效果 | 使用场景 |
|------|------|---------|
| 环绕 (orbit/arc) | 围绕主体旋转 | 英雄时刻、产品展示 |
| 一镜到底 (long take) | 无剪切沉浸感 | 动作长镜头、空间探索 |
| 希区柯克变焦 (dolly zoom) | 空间扭曲、心理不安 |  revelation、恐惧时刻 |
| 升降摇臂 (crane) | 垂直升降运动 | 史诗开场、结尾拉远 |
| 甩镜 (whip pan) | 快速转场、能量转换 | 场景切换、喜剧节拍 |
| 手持 (handheld) | 真实感、紧迫感 | 纪实、追逐、混乱 |
| 稳定器 (steadicam) | 流畅跟拍 | 行走对话、空间穿越 |
| FPV 穿越机 | 高速穿越 | 极限运动、空间穿越 |

### 2.3 运镜与叙事节奏匹配

| 叙事阶段 | 运镜偏好 | 节奏 |
|---------|---------|------|
| 铺垫 | 平稳推镜头/固定/缓慢 pan | 舒缓，留足环境建立时间 |
| 发展 | 跟拍/中速 pan/tilt | 渐快，动作幅度增大 |
| 转折 | 甩镜/希区柯克变焦/突然静止 | 突变，对比强烈 |
| 高潮 | 环绕/手持/快速跟拍 | 最快最强烈 |
| 收尾 | 拉镜头/升降拉远/固定 | 放缓，回归平静 |

### 2.4 相邻镜头的运镜变化规则

- 相邻镜头的景别、角度或运镜应有变化
- 避免连续 3 镜以上无理由同景别
- 递进关系时镜头变化服务于内容推进
- 续写关系时镜头变化服务于同一主题的多角度呈现

## 3. 视觉连续性维护

### 3.1 跨 Element 衔接

- **开头衔接**：当前 Element 的第一个 Shot 应与前一个 Element 的结尾在情绪、动作阶段、场景环境上自然延续
- **场景延续**：同一场景的背景环境、光照条件、道具位置保持一致
- **动作递进**：前一个 Element 结尾是动作中间阶段时，当前 Element 开头承接下一阶段
- **情绪连贯**：角色情绪状态从前一个 Element 结尾延续，不出现无铺垫的情绪跳变

### 3.2 视觉连续性铁律

- **动作衔接**：相邻镜主体动作阶段自然递进，不跳跃或重复
- **朝向守恒**：主体画面朝向在相邻镜头间保持一致
- **场景可延续**：背景环境、道具位置、光照条件在连续镜头中稳定不变
- **外观一致**：服装、发型、体型、颜色在 Element 全部镜头中一致
- **道具状态**：道具在连续镜头中的位置、数量、状态保持一致或合理递进

## 4. 声音设计

### 4.1 声音层次

| 层次 | 说明 | 示例 |
|------|------|------|
| 环境音 | 场景的基础声底 | 风声、雨声、城市喧嚣、森林鸟鸣 |
| 动作音 | 角色动作产生的声音 | 脚步声、门吱呀、玻璃碰撞 |
| 对话 | 角色台词 | 语气、音量、情感 |
| 配乐 | 背景音乐（仅描述方向） | `soft piano in background`, `upbeat electronic` |

### 4.2 声音与画面同步

- 环境音与场景绑定：同一场景的环境音保持一致
- 动作音与动作同步：每个可见动作都应有对应声音
- 对话与口型同步：台词节奏与角色口型匹配
- 配乐描述保持抽象：描述音乐方向（`textural`），不要写完整配乐方案

### 4.3 声音设计禁忌

- **禁止配乐描述**：音效列仅环境音 + 动作音/拟音，禁止 BGM/配乐/音乐/旋律/乐器氛围烘托
- **例外**：剧情中角色实际演奏乐器的物理声源是允许的

## 5. 叙事节奏

### 5.1 张力曲线

相邻 Shot 的叙事节奏应形成连贯的张力曲线：

```
铺垫 → 发展 → 转折 → 高潮 → 收尾
舒缓    渐快    突变    最强烈   放缓
```

不出现无意义的节奏跳跃。

### 5.2 内容类型适配

不同类型的内容在 prompt 中有不同侧重点：

| 类型 | 侧重 |
|------|------|
| 叙事类 | 角色表情与情绪、场景氛围、对白可读性 |
| 展示类 | 产品/主体完整性、材质细节、光线均匀、色彩还原 |
| 动作类 | 动态模糊控制、运动主体轮廓清晰度、画面信息密度 |
| 宠物类 | 毛发质感、眼神方向、与环境互动连续性 |

## 6. 视频 Prompt 示例

```
[Shot]: Medium close-up, slight low angle
[Camera]: Slow dolly-in
[Subject]: A weathered fisherman in his 60s, salt-and-pepper beard,
           dark wool sweater, calloused hands gripping a rope
[Action]: He pulls the rope hand-over-hand, muscles straining,
          then pauses and looks out to sea
[Setting]: Wooden dock at dawn, calm grey ocean, distant fog bank,
           seagulls wheeling overhead
[Lighting]: Soft overcast with warm break in clouds on the horizon,
            gentle rim light from the rising sun
[Style]: Documentary cinematography, 35mm film grain,
         muted earth tones with a cold blue-grey palette
[Audio]: Rope creaking, water lapping, distant gull cries, wind
```
