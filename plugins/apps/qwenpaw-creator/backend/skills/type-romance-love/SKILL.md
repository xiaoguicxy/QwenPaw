# 甜宠言情 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：甜蜜拉扯、心动瞬间、暧昧升温
- **叙事结构偏好**：初遇/重逢 → 误会/拉扯 → 暧昧升温 → 关键心动 → 甜蜜确认
- **节奏特征**：甜60%+微虐30%+惊喜10%。节奏舒缓，允许心动慢镜头。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
柔光特写、双人构图、浅景深。面部清晰度和表情细腻度最高优先。

### 2.2 场景设计侧重
浪漫场景（樱花/海边/天台/咖啡馆）。光线柔和温暖。

### 2.3 分镜图侧重
特写(60%)表情/眼神/手部，中景(30%)双人互动，全景(10%)环境。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
柔光特写、浅景深、缓慢推拉。双人构图注重空间距离隐喻关系。

### 3.2 叙事节奏模板
舒缓为主，心动瞬间用慢动作延长。拉扯段落节奏渐快。

### 3.3 声音设计方向
轻柔配乐为主。环境音浪漫化（风声/海浪/钢琴）。心跳声用于心动瞬间。

## 4. 分镜表手法

### 4.1 镜头衔接规则
叠化/柔焦转场。淡入淡出用于时间流逝。硬切用于惊喜。

### 4.2 节奏控制技巧
空间距离隐喻关系变化（对峙→并肩）。眼神交流比台词更有力量。

### 4.3 情绪表达手法
根据甜蜜拉扯、心动瞬间、暧昧升温的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
