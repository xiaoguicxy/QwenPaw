# 音乐 MV · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：节奏驱动、视觉律动、情绪渲染
- **叙事结构偏好**：前奏(环境建立) → 主歌(叙事/表演) → 副歌(高潮视觉) → 间奏(变化) → 尾奏(收束)
- **节奏特征**：严格跟随音乐节拍。每个cut对齐节拍点。副歌段最密集。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
风格化优先。歌手/乐手表演画面。视觉特效服务于音乐情绪。

### 2.2 场景设计侧重
多场景快速切换。每个场景对应歌曲段落。场景服务于音乐情绪。

### 2.3 分镜图侧重
特写(40%)表演/表情，中景(30%)演奏/舞蹈，全景(30%)场景/特效。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
快切、多场景、风格化。运镜跟随音乐节拍。副歌段运镜最激烈。

### 3.2 叙事节奏模板
严格跟随音乐结构。前奏舒缓→主歌渐强→副歌爆发→间奏变化→尾奏收束。

### 3.3 声音设计方向
音乐是唯一核心。所有视觉服务于音乐。不需要额外音效设计。

## 4. 分镜表手法

### 4.1 镜头衔接规则
硬切对齐节拍。闪白/闪黑用于重拍。叠化用于抒情段落。

### 4.2 节奏控制技巧
先听音乐10遍再开始创作。每个cut都要对齐节拍。歌词可视化是加分项但不是必须。

### 4.3 情绪表达手法
根据节奏驱动、视觉律动、情绪渲染的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
