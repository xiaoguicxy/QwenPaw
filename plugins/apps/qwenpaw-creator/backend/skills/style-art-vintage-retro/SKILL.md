# 复古怀旧 · 视觉风格

## 1. 风格定义

- **世界观/美学基调**：对过去时代的温暖怀念。不完美的画质是情感的一部分。
- **核心视觉特征**：褪色暖调, 胶片颗粒, 暗角, CRT扫描线, 怀旧
- **参考作品**：见各风格经典影片/动画

## 2. 严禁内容

以下元素与本风格冲突，不得在 prompt 中使用：
- 现代数字感
- 高饱和清晰
- 冷色调
- 未来科技

## 3. 图片 Prompt 规范

### 3.1 风格前缀锚点（5-10 词）
所有图片 prompt 共享的风格方向（适配不照搬）：
`褪色暖调, 胶片颗粒, 暗角, 复古怀旧 aesthetic`

### 3.2 色彩体系
褪色暖色调，像老照片/旧胶片。黄色/橙色/棕色为主。饱和度低。有时偏绿（VHS）或偏红（老照片）。

### 3.3 光照体系
暖色光源（白炽灯/烛光/老式日光灯）。柔和不刺眼。光晕和镜头眩光常见。

### 3.4 角色设计 prompt 规范
复古装扮（根据年代）。发型/服装符合特定时代。肤色偏暖偏黄。

### 3.5 场景设计 prompt 规范
复古场景（老式客厅/街边小店/老学校/旧游乐场）。注重时代道具（老电视/收音机/电话）。

### 3.6 分镜图 prompt 规范
- 分镜图使用本风格的色彩和光照基准
- 画质限定词与风格匹配
- 相邻宫格保持风格一致

## 4. 视频 Prompt 规范

### 4.1 视频风格锚点（1-2 句）
复古怀旧风格，褪色暖调，胶片颗粒，暗角，怀旧温暖质感。

### 4.2 运镜偏好
模拟老式摄影机/相机。画面抖动（手持8mm）。变焦缓慢（老式镜头）。暗角和畸变。

### 4.3 色彩/光影方向
与图片保持一致的色彩体系和光照方向。视频中光影可以随叙事变化，但风格基调不变。

## 5. 完整 Prompt 示例

### 5.1 角色/场景设计图 prompt 示例
```
Medium shot, vintage 1970s film. A family of four on a plaid couch in a wood-paneled living room, warm incandescent light. Father in brown polyester, mother in floral dress. Faded warm tones, visible film grain, soft vignette, slight lens flare. Muted earth tones. 16:9.
```

### 5.2 视频 prompt 示例
```
Shot 1 (medium, slight handheld shake, 3s):
Vintage 1980s VHS. A teenager in denim jacket walks into a neon-lit arcade, rows of cabinet screens glowing. Track lighting on polished floor. Slight tracking distortion.

Shot 2 (close-up, slow zoom, 2s):
Hand inserts a coin. Screen reflects in eyes. CRT scan lines visible. Pixelated explosion flashes. Warm amber, film grain, color bleeding.

Style: Vintage retro, faded warm tones, film grain/VHS, vignette, nostalgic warmth.
Audio: Arcade beeps, coin drop, 80s synth, distant laughter.
```
