# 恐怖悬疑 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：紧张、未知、恐惧、不安
- **叙事结构偏好**：日常建立 → 异常暗示 → 恐惧积累 → 真相揭示/爆发 → 余悸
- **节奏特征**：慢热积累→突然爆发。安静段落比喧闹更可怕。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
暗调、负空间、Dutch angle。阴影中隐藏的信息。面部恐惧表情特写。

### 2.2 场景设计侧重
日常场景中的异常。熟悉的空間变得陌生。黑暗角落/镜子/门缝。

### 2.3 分镜图侧重
特写(40%)恐惧表情/线索，中景(30%)探索，全景(30%)负空间/黑暗。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
暗调、负空间、Dutch angle。缓慢推进制造压迫感。突然甩镜用于惊吓。

### 3.2 叙事节奏模板
慢热积累，安静段落拉长不安。爆发必须突然。爆发后回归安静制造余悸。

### 3.3 声音设计方向
安静是恐怖的工具。低频嗡鸣/不和谐音/突然静默。脚步声/门吱呀等日常音效放大。

## 4. 分镜表手法

### 4.1 镜头衔接规则
硬切用于突然惊吓。叠化用于不安过渡。黑场用于未知。

### 4.2 节奏控制技巧
看不见的比看见的更可怕。暗示比展示更有效。不要过早揭示威胁。

### 4.3 情绪表达手法
根据紧张、未知、恐惧、不安的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
