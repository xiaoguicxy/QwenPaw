# 黏土定格动画 · 视觉风格

## 1. 风格定义

- **世界观/美学基调**：手工制作的微缩世界，所有物体都有黏土/手工质感。保留了手工制作的温度和不完美。
- **核心视觉特征**：黏土质感, 指纹痕迹, 微缩场景, 逐帧感, 手工温度
- **参考作品**：见各风格经典影片/动画

## 2. 严禁内容

以下元素与本风格冲突，不得在 prompt 中使用：
- 光滑CG渲染
- 写实材质
- 完美对称
- 数字特效感

## 3. 图片 Prompt 规范

### 3.1 风格前缀锚点（5-10 词）
所有图片 prompt 共享的风格方向（适配不照搬）：
`黏土质感, 指纹痕迹, 微缩场景, 黏土定格动画 aesthetic`

### 3.2 色彩体系
柔和的实物色彩，略带灰度。像真实黏土/布料的色彩。不过度饱和。

### 3.3 光照体系
模拟真实微缩场景的打光。可见光源方向。柔和阴影。有时可见布景边缘。

### 3.4 角色设计 prompt 规范
黏土人物，可见指纹痕迹。比例略夸张但不过分。表情通过整体姿态传达。

### 3.5 场景设计 prompt 规范
微缩场景感，所有物体都有手工质感。布料/纸板/木头/黏土混合材质。

### 3.6 分镜图 prompt 规范
- 分镜图使用本风格的色彩和光照基准
- 画质限定词与风格匹配
- 相邻宫格保持风格一致

## 4. 视频 Prompt 规范

### 4.1 视频风格锚点（1-2 句）
黏土定格动画风格，手工质感，指纹痕迹，微缩场景，逐帧律动。

### 4.2 运镜偏好
模拟定格动画的微妙抖动。帧率感（非60fps流畅）。缓慢平稳的运动。

### 4.3 色彩/光影方向
与图片保持一致的色彩体系和光照方向。视频中光影可以随叙事变化，但风格基调不变。

## 5. 完整 Prompt 示例

### 5.1 角色/场景设计图 prompt 示例
```
Close-up, claymation style. A small round clay penguin with visible fingerprint textures, tiny orange beak, waddles on a snowy landscape of white felt and sugar crystals. Tiny fabric aurora above. Warm desk lamp lighting, soft shadows on wooden table. 16:9.
```

### 5.2 视频 prompt 示例
```
Shot 1 (medium, static with subtle shake, 3s):
Claymation. A tiny clay baker with white chef hat, round body, flour-dusted apron kneads dough on a miniature wooden table. Visible fingerprints. Stop-motion jitter.

Shot 2 (close-up, push-in, 2s):
The baker picks up a tiny rolling pin, rolls dough flat. Flour poofs up. Eyes squint with concentration.

Style: Claymation, visible fingerprints, miniature set, warm lighting, frame-by-frame.
Audio: Clay squishing, rolling pin on wood, flour poof, quiet humming.
```
