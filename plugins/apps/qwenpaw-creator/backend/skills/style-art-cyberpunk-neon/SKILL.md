# 赛博朋克 · 视觉风格

## 1. 风格定义

- **世界观/美学基调**：高科技低生活的未来世界观。霓虹灯与黑暗并存，科技与衰败共存。
- **核心视觉特征**：霓虹光效, 暗色调, 高对比度, 雨夜反射, 未来
- **参考作品**：《银翼杀手 2049》《赛博朋克：边缘行者》

## 2. 严禁内容

以下元素与本风格冲突，不得在 prompt 中使用：
- 自然田园
- 明亮暖色调
- 复古怀旧
- 卡通可爱

## 3. 图片 Prompt 规范

### 3.1 风格前缀锚点（5-10 词）
所有图片 prompt 共享的风格方向（适配不照搬）：
`霓虹光效, 暗色调, 高对比度, 赛博朋克 aesthetic`

### 3.2 色彩体系
暗色基底+霓虹高光。品红/青色/紫色/电蓝为主。黑色和深灰占大部分。霓虹色仅占5-15%。

### 3.3 光照体系
霓虹光源为主。雨夜反射放大光效。体积光穿过烟雾。强烈明暗对比。

### 3.4 角色设计 prompt 规范
未来感装扮（发光纹身/机械义肢/LED配饰）。面部被霓虹光染色。暗处隐藏细节。

### 3.5 场景设计 prompt 规范
未来城市街道（全息广告/飞行车/密集建筑）。雨夜是标志性场景。蒸汽/烟雾/水洼反射。

### 3.6 分镜图 prompt 规范
- 分镜图使用本风格的色彩和光照基准
- 画质限定词与风格匹配
- 相邻宫格保持风格一致

## 4. 视频 Prompt 规范

### 4.1 视频风格锚点（1-2 句）
赛博朋克风格，霓虹光效，暗色调高对比度，雨夜反射，未来科技感。

### 4.2 运镜偏好
低角度仰拍展示建筑压迫感。广角镜头扭曲透视。快速剪辑表现信息过载。

### 4.3 色彩/光影方向
与图片保持一致的色彩体系和光照方向。视频中光影可以随叙事变化，但风格基调不变。

## 5. 完整 Prompt 示例

### 5.1 角色/场景设计图 prompt 示例
```
Medium shot, cyberpunk neon style. A female hacker with short asymmetric hair, one cybernetic eye glowing cyan, dark jacket with LED circuits, stands in a rain-soaked alley. Neon signs in Japanese/Chinese reflect in puddles, magenta, cyan, purple. High contrast, dark shadows, volumetric fog. 16:9.
```

### 5.2 视频 prompt 示例
```
Shot 1 (wide, slow dolly-in, 3s):
Cyberpunk. A towering megastructure at night, hundreds of neon-lit windows stacking into smog. Holographic ads flicker between buildings. Rain falls through neon beams.

Shot 2 (medium, tracking, 3s):
A hooded figure walks through a night market. Neon food signs reflect off wet shoulders. Steam from vending machines. Cybernetic hand grips a data chip, cyan light leaking.

Style: Cyberpunk, neon on dark, high contrast, rain reflections, volumetric fog, futuristic decay.
Audio: Neon buzz, rain on metal, distant synth, crowd murmur, electronic beeps.
```
