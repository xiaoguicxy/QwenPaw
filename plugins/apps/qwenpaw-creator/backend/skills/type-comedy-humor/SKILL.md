# 喜剧搞笑 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：预期违背、荒谬感、笑中带泪
- **叙事结构偏好**：正常铺垫 → 预期建立 → 意外反转(笑点) → 反应镜头 → 新一轮铺垫
- **节奏特征**：铺垫→抖包袱循环。三遍法则。节奏即喜感，时机就是一切。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
表情夸张是核心。反应镜头比动作镜头更重要。角色碰撞的构图。

### 2.2 场景设计侧重
日常场景产生荒谬感。环境服务于喜剧反差。

### 2.3 分镜图侧重
特写(50%)表情反应，中景(30%)互动，全景(20%)荒谬场景。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
反应镜头、全景荒谬、错位构图。急推反应、稳定vs混乱对比。

### 3.2 叙事节奏模板
铺垫可以慢，抖包袱必须快。留白让笑点发酵。不连续堆笑点。

### 3.3 声音设计方向
音效辅助笑点（突然静默/反差配乐/夸张音效）。沉默也是喜感工具。

## 4. 分镜表手法

### 4.1 镜头衔接规则
硬切用于反差。甩镜用于混乱。假正经转场（突然严肃→突然崩塌）。

### 4.2 节奏控制技巧
最高级的喜剧是角色性格碰撞产生的荒谬，不是抖机灵。笑中带泪比纯搞笑更高级。

### 4.3 情绪表达手法
根据预期违背、荒谬感、笑中带泪的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
