# 微电影/短片 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：完整叙事弧、情绪余韵、回味感
- **叙事结构偏好**：建立(15%) → 发展(30%) → 转折(25%) → 高潮(20%) → 余韵(10%)
- **节奏特征**：舒展，平均8-15秒/Element。允许留白和静默。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
全景建立环境，中景叙事，特写收束情绪。三者平衡。

### 2.2 场景设计侧重
场景讲述故事。环境细节暗示角色内心。光影变化标记叙事进程。

### 2.3 分镜图侧重
全景(20%)、中景(40%)、特写(40%)。注重构图美感和叙事效率。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
稳定运镜为主。缓慢推拉营造氛围。长镜头用于关键情绪段落。

### 3.2 叙事节奏模板
起承转合完整。允许舒缓段落。高潮后有余韵。不急于推进。

### 3.3 声音设计方向
环境音营造沉浸感。配乐跟随情绪弧。留白和静默是重要叙事工具。

## 4. 分镜表手法

### 4.1 镜头衔接规则
叠化/淡入淡出为主。硬切用于节奏加速。匹配剪辑用于主题关联。

### 4.2 节奏控制技巧
结尾留白比圆满收尾更有力。每个场景都要推动叙事或揭示角色。

### 4.3 情绪表达手法
根据完整叙事弧、情绪余韵、回味感的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
