# 产品展示 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：产品美感、品质感、向往感
- **叙事结构偏好**：产品出场 → 细节展示 → 使用场景 → 效果呈现 → 品牌收尾
- **节奏特征**：平稳优雅，重点停留。每个细节给足时间。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
产品完整性、材质细节、光线均匀、色彩还原准确优先。微距展示质感。

### 2.2 场景设计侧重
干净背景或精心布置的场景。光线均匀无死角。道具服务于产品。

### 2.3 分镜图侧重
特写(50%)展示细节，中景(30%)展示使用，全景(20%)展示环境。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
微距特写、360度环绕、缓慢推拉。稳定器保证画面稳定。

### 3.2 叙事节奏模板
均匀节奏，重点处放慢。不允许 rushed feeling。每个镜头都有明确目的。

### 3.3 声音设计方向
精致的音效（产品触感/环境音）。配乐优雅不抢戏。无台词或极简旁白。

## 4. 分镜表手法

### 4.1 镜头衔接规则
平滑过渡为主。叠化/缩放转场。避免硬切打断优雅感。

### 4.2 节奏控制技巧
产品永远是画面主体。光线是产品片的灵魂。避免过度后期改变产品真实色彩。

### 4.3 情绪表达手法
根据产品美感、品质感、向往感的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
