# 模型适配通用指南

本 skill 指导如何根据当前配置的视频/图片模型调整 prompt 策略和参数选择。

## 1. 视频模型适配

### 1.1 HappyHorse 系

**模型名前缀**：`happyhorse`

**参数约束**：
- 分辨率：720P / 1080P
- 宽高比：16:9, 9:16, 3:4, 4:3, 4:5, 5:4, 1:1, 9:21, 21:9（共 9 种）
- 时长：3-15 秒（整数）
- 参考图：1-9 张（r2v 模式）；video_edit 最多 5 张参考图
- 模式矩阵：r2v, t2v, i2v, video_edit

**Prompt 要求**：
- 参考指代必须用 `[Image N]` 格式（1-based，按 media 数组顺序）
- 每次指代必须说明该参考图中的具体对象
- 视频 prompt 长度：150-300 词
- **不发送** `prompt_extend` 参数（HappyHorse 不支持）

**模式特有约束**：
- r2v：仅支持参考图片，不支持参考视频
- t2v：纯文本生视频，不传参考素材
- i2v：首帧生视频，画幅跟随首帧，不传 ratio
- video_edit：输入视频 3-60 秒，超过 15 秒只取前 15 秒

### 1.2 Wan 系

**模型名前缀**：`wan`

**参数约束**：
- 分辨率：720P / 1080P
- 宽高比：16:9, 9:16, 1:1, 4:3, 3:4（共 5 种）
- 时长：3-15 秒（整数）
- 参考图：最多 9 张
- 模式矩阵：r2v, t2v, i2v（无 video_edit）

**Prompt 要求**：
- 参考指代用自然语言描述（不需要 [Image N] 格式）
- 视频 prompt 长度：200-400 词（Wan 微调于长 caption，奖励详细描述）
- 发送 `prompt_extend=False`（禁用自动扩写，保持 prompt 忠实度）

### 1.3 Seedance2 系

**模型名包含**：`seedance`

**参数约束**：
- 分辨率：480p / 720p / 1080p
- 宽高比：16:9, 9:16, 1:1, 4:3, 3:4, 21:9, auto（共 7 种）
- 时长：4-15 秒（整数）
- 模式矩阵：仅 r2v

**Prompt 要求**：
- 视频 prompt 长度：200-400 词（主镜头）/ 80-150 词（插入镜头）
- 参考媒体通过 public URL 或 base64 data URL 传递
- 不支持本地视频文件作为参考

**Seedance2 独有优势**：
- 原生同步音频（语音 + 音效 + 环境音一次生成）
- 多镜头单次生成（用 Shot 1/Shot 2 格式）
- 导演级镜头控制（精确术语：slow dolly-in, arc shot, Dutch tilt）
- 唇同步（`Character says: "line."` 引号内 ≤6 词）

### 1.4 模型选择决策

| 需求 | 推荐模型 | 原因 |
|------|---------|------|
| 电影级质感、多镜头、同步音频 | Seedance2 | 原生音频 + 多镜头 + 导演级控制 |
| 丰富参考图、精确指代 | HappyHorse | [Image N] 协议 + 9 种宽高比 |
| 通用生成、长 prompt | Wan | 长 caption 微调 + prompt_extend 控制 |
| 仅 r2v、成本敏感 | Seedance2 fast | 快速变体，$1.21/clip |

## 2. 图片模型适配

### 2.1 DashScope（qwen-image 系）

**默认模型**：`qwen-image-2.0-pro`

**尺寸映射**：
| 宽高比 | 像素尺寸 |
|--------|---------|
| 16:9 | 1664×928 |
| 9:16 | 928×1664 |
| 1:1 | 1328×1328 |
| 4:3 | 1472×1104 |
| 3:4 | 1104×1472 |
| 3:2 | 1472×976 |
| 2:3 | 976×1472 |

**支持模式**：generate / edit / translate
**Prompt 长度**：30-60 词
**特点**：国风/插画表现力强；translate 模式可做风格迁移

### 2.2 OpenAI（gpt-image 系）

**默认模型**：`gpt-image-2`

**尺寸映射**：
| 宽高比 | 像素尺寸 |
|--------|---------|
| 16:9 | 1536×1024 |
| 9:16 | 1024×1536 |
| 1:1 | 1024×1024 |
| 4:3 | 1024×768 |
| 3:4 | 768×1024 |
| 21:9 | 2560×1080 |
| 3:2 | 1536×1024 |
| 2:3 | 1024×1536 |

**Quality 参数**：low / medium / high（默认 low）
**Prompt 长度**：20-40 词
**特点**：最佳文字渲染能力；复杂指令跟随能力强；支持多图合成

### 2.3 图片模型选择决策

| 场景类型 | 推荐模型 | 原因 |
|---------|---------|------|
| 真实照片 | Pexels/Unsplash（免费）→ DashScope | 真实照片 > AI 生成 |
| 抽象/概念插图 | DashScope | AI 擅长自定义概念 |
| 含文字/标签 | OpenAI Image | 最佳文字渲染 |
| 风格迁移 | DashScope (translate 模式) | 原生风格迁移 |
| 多图合成 | OpenAI Image | 多图合成能力 |
| 国风/插画 | DashScope | 东方美学表现力强 |
|  Logo/品牌 | OpenAI Image | SVG 支持 |

## 3. 通用最佳实践

### 3.1 跨模型一致性

- 分镜图优先引用 lineup 作为参考链首位（群体锚点）
- 视频 prompt 首段衔接前一个 Element 的结尾状态
- 不同模型的 prompt 长度调节：模型越"聪明"（如 Seedance2），prompt 可以越长越详细
- 风格化项目中，video_reference_version_ids 只引用角色设计/分镜 ArtifactVersion，不引用真人来源照片

### 3.2 成本意识

- 预览阶段用低分辨率/快速变体
- 锁定 seed 后迭代，避免重复烧钱
- 批量生成时先 klein 迭代再 pro 定稿

### 3.3 失败恢复

- 429（限流）→ 等待后重试
- 5xx（服务端错误）→ 重试最多 2 次
- Safety 拒绝 → 检查参考图是否含真人面部（风格化项目常见），调整参考图后重试
- 模型不存在 → 检查 mode-derived model name 是否正确
