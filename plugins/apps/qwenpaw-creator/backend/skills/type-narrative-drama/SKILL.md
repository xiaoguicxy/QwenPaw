# 叙事短剧 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：情绪张力、角色冲突、命运转折
- **叙事结构偏好**：钩子开场(1.5s) → 冲突建立 → 升级对抗 → 高潮爆发 → 卡点收尾
- **节奏特征**：紧凑，平均3-5秒/Element。每Element至少一个情绪爆点。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
角色表情与情绪传达优先。面部清晰度不低于中景。特写捕捉微妙表情变化。

### 2.2 场景设计侧重
场景氛围服务于情绪。光线/色调随情绪变化（冲突→高对比，和解→柔光）。

### 2.3 分镜图侧重
特写和近景为主（60%），中景辅助（30%），全景建立（10%）。正反打对话构图。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
特写表情、过肩对话、正反打。手持增加紧张感。快速推拉用于情绪转折。

### 3.2 叙事节奏模板
铺垫(10%) → 冲突建立(25%) → 升级(30%) → 高潮(25%) → 卡点(10%)。相邻Shot节奏递进。

### 3.3 声音设计方向
环境音服务于情绪（安静→紧张，爆发→嘈杂）。配乐跟随张力曲线。台词是核心。

## 4. 分镜表手法

### 4.1 镜头衔接规则
硬切为主，偶尔叠化表示时间流逝。情绪转折处可用甩镜/黑场。

### 4.2 节奏控制技巧
卡点设计：每集结尾留悬念。情绪爆点间隔不超过15秒。台词精简有力。

### 4.3 情绪表达手法
根据情绪张力、角色冲突、命运转折的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
