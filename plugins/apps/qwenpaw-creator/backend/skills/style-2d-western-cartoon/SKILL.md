# 欧美卡通风 · 视觉风格

## 1. 风格定义

- **世界观/美学基调**：欧美电视动画美学，夸张变形、弹性物理、幽默优先。涵盖喜剧、冒险、儿童等题材。
- **核心视觉特征**：夸张比例, 粗线条, 高饱和, 弹性运动, 幽默
- **参考作品**：见各风格经典影片/动画

## 2. 严禁内容

以下元素与本风格冲突，不得在 prompt 中使用：
- 日式大眼睛
- 写实比例
- 暗色调/恐怖元素
- 复杂光影

## 3. 图片 Prompt 规范

### 3.1 风格前缀锚点（5-10 词）
所有图片 prompt 共享的风格方向（适配不照搬）：
`夸张比例, 粗线条, 高饱和, 欧美卡通风 aesthetic`

### 3.2 色彩体系
高饱和原色为主（红/蓝/黄/绿）。角色用鲜明色彩区分。背景丰富但不抢戏。

### 3.3 光照体系
平面着色为主，简单阴影。不使用复杂光影。整体明亮欢快。

### 3.4 角色设计 prompt 规范
夸张比例（大头小身/大嘴/大眼）。表情极度夸张。肢体语言夸张。辨识度高。

### 3.5 场景设计 prompt 规范
色彩丰富的卡通世界。日常场景夸张化。背景细节服务于喜剧。

### 3.6 分镜图 prompt 规范
- 分镜图使用本风格的色彩和光照基准
- 画质限定词与风格匹配
- 相邻宫格保持风格一致

## 4. 视频 Prompt 规范

### 4.1 视频风格锚点（1-2 句）
欧美卡通风格，夸张比例，粗线条，高饱和色彩，弹性运动，幽默感。

### 4.2 运镜偏好
夸张的镜头运动。弹性变形（squash and stretch）。快速推拉用于喜剧节拍。

### 4.3 色彩/光影方向
与图片保持一致的色彩体系和光照方向。视频中光影可以随叙事变化，但风格基调不变。

## 5. 完整 Prompt 示例

### 5.1 角色/场景设计图 prompt 示例
```
Wide shot, Western cartoon style, bold outlines, exaggerated proportions. A clumsy orange cat with huge eyes and tiny legs tries to squeeze through a mailbox, body comically squished. Bright suburban background. High saturation, flat coloring. 16:9.
```

### 5.2 视频 prompt 示例
```
Shot 1 (medium, static, 2s):
Western cartoon. A chubby dog with floppy ears, red collar, sits before a bone cookie, eyes wide. Tongue out, tail wagging blur.

Shot 2 (fast zoom in, 1s):
He lunges but a tiny mouse catches it first. Dog face freezes, eyes shrink to dots.

Style: Western cartoon, exaggerated proportions, bold outlines, high saturation, squash-and-stretch.
Audio: Comical boing, fast paws, record scratch, tiny squeak.
```
