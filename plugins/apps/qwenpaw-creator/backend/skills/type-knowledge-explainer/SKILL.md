# 知识科普 · 导演叙事手法

## 1. 类型定义

- **核心情绪基调**：信息清晰、获得感、好奇心满足
- **叙事结构偏好**：问题提出 → 背景铺垫 → 核心讲解(多段) → 总结回顾 → 延伸思考
- **节奏特征**：节奏明快，每段一个知识点。平均5-8秒/Element。

## 2. 图片 Prompt 侧重

### 2.1 角色设计侧重
信息清晰优先。图表/示意图/数据可视化。均匀光照确保可读性。

### 2.2 场景设计侧重
简洁背景不抢信息。图表/文字叠加区域预留空间。

### 2.3 分镜图侧重
中景(50%)讲解，特写(30%)细节/图表，全景(20%)建立。

## 3. 视频 Prompt 侧重

### 3.1 镜头语言偏好
中景稳定为主。偶尔特写强调重点。运镜克制，信息优先。

### 3.2 叙事节奏模板
分段清晰，每段一知识点。节奏均匀不拖沓。重点处可放慢。

### 3.3 声音设计方向
旁白是核心。环境音极低或无。配乐轻柔不干扰。关键数据配合音效强调。

## 4. 分镜表手法

### 4.1 镜头衔接规则
硬切为主。数据/图表切换用叠化。段落间可用图形转场。

### 4.2 节奏控制技巧
旁白按4.5字/秒估算时长。每段旁白1-3句，单句不超25字。文字用overlay叠加。

### 4.3 情绪表达手法
根据信息清晰、获得感、好奇心满足的核心情绪，通过镜头语言、光影变化、运镜节奏来传达。相邻Shot的情绪应形成连贯的张力曲线。
