# 扁平运动图形 · 视觉风格

## 1. 风格定义

- **世界观/美学基调**：现代平面设计美学，极简主义与大胆图形结合。信息传达优先于装饰。
- **核心视觉特征**：几何形状, 大胆色彩, 无渐变, 干净边缘, 极简
- **参考作品**：见各风格经典影片/动画

## 2. 严禁内容

以下元素与本风格冲突，不得在 prompt 中使用：
- 写实光影
- 3D渲染质感
- 复杂纹理
- 渐变/阴影/模糊效果

## 3. 图片 Prompt 规范

### 3.1 风格前缀锚点（5-10 词）
所有图片 prompt 共享的风格方向（适配不照搬）：
`几何形状, 大胆色彩, 无渐变, 扁平运动图形 aesthetic`

### 3.2 色彩体系
高饱和大胆配色，每个场景2-3种主色。品牌色优先。对比色用于强调。背景常为纯色。

### 3.3 光照体系
无光影效果。平面着色，所有元素等亮度。不使用阴影或高光。

### 3.4 角色设计 prompt 规范
极简几何化人物。圆形头部、简单肢体。无面部细节或极简表情。服装用纯色块区分。

### 3.5 场景设计 prompt 规范
极简背景，纯色或简单图案。信息元素（图标/图表/箭头/数字）是视觉主体。

### 3.6 分镜图 prompt 规范
- 分镜图使用本风格的色彩和光照基准
- 画质限定词与风格匹配
- 相邻宫格保持风格一致

## 4. 视频 Prompt 规范

### 4.1 视频风格锚点（1-2 句）
扁平运动图形风格，几何形状，大胆色彩，干净边缘，节奏感强。

### 4.2 运镜偏好
图形自身的运动即是运镜。缩放/旋转/位移/形变。节奏感强，与音乐节拍同步。

### 4.3 色彩/光影方向
与图片保持一致的色彩体系和光照方向。视频中光影可以随叙事变化，但风格基调不变。

## 5. 完整 Prompt 示例

### 5.1 角色/场景设计图 prompt 示例
```
Flat design illustration, bold colors, clean edges, no gradients, white background. A software developer at a desk with dual monitors, geometric shapes, code symbols floating. Palette: coral, teal, navy, yellow. Minimal, no shadows. 16:9.
```

### 5.2 视频 prompt 示例
```
Shot 1 (static wide, 2s):
Flat motion graphics. A large coral circle labeled Problem sits center-screen on teal background. Smaller navy shapes orbit.

Shot 2 (zoom in, 2s):
The circle splits into 3 pieces, each transforming into an icon (magnifying glass, lightbulb, checkmark). Yellow arrows connect them.

Style: Flat design, bold colors, clean edges, no gradients, geometric motion.
Audio: Soft whoosh, subtle click on icon appearance.
```
