# 奇幻梦境 · 视觉风格

## 1. 风格定义

- **世界观/美学基调**：超越物理法则的幻想世界。一切皆有可能，美是唯一规则。
- **核心视觉特征**：超现实, 发光粒子, 渐变天空, 柔焦光晕, 梦幻
- **参考作品**：《千与千寻》《红辣椒》（超现实幻想世界）

## 2. 严禁内容

以下元素与本风格冲突，不得在 prompt 中使用：
- 写实物理
- 暗黑暗怖
- 工业机械
- 日常平凡

## 3. 图片 Prompt 规范

### 3.1 风格前缀锚点（5-10 词）
所有图片 prompt 共享的风格方向（适配不照搬）：
`超现实, 发光粒子, 渐变天空, 奇幻梦境 aesthetic`

### 3.2 色彩体系
梦幻渐变色彩。粉紫/蓝绿/金橙过渡。发光色彩（荧光/星光）。柔和但丰富。

### 3.3 光照体系
魔法光源（发光植物/浮空光球/星光）。柔焦光晕。体积光穿过云层/森林。逆光剪影常见。

### 3.4 角色设计 prompt 规范
梦幻人物，略带透明感。飘逸的头发/衣物。发光元素（翅膀/光环/魔法纹）。

### 3.5 场景设计 prompt 规范
超现实风景（浮空岛/水晶森林/星空海洋/云端城堡）。粒子效果贯穿。

### 3.6 分镜图 prompt 规范
- 分镜图使用本风格的色彩和光照基准
- 画质限定词与风格匹配
- 相邻宫格保持风格一致

## 4. 视频 Prompt 规范

### 4.1 视频风格锚点（1-2 句）
奇幻梦境风格，超现实构图，发光粒子，渐变色彩，柔焦光晕，梦幻飘逸。

### 4.2 运镜偏好
漂浮感运镜。缓慢升降/环绕。失重感。有时故意模糊焦点营造梦境。

### 4.3 色彩/光影方向
与图片保持一致的色彩体系和光照方向。视频中光影可以随叙事变化，但风格基调不变。

## 5. 完整 Prompt 示例

### 5.1 角色/场景设计图 prompt 示例
```
Wide shot, fantasy dreamscape. A giant glowing crystal tree grows from a floating island, roots trailing luminous vines into clouds. Bioluminescent flowers release floating light spores. Gradient sky from deep violet to rose gold. Soft lens flare, ethereal glow, magical particles. 16:9.
```

### 5.2 视频 prompt 示例
```
Shot 1 (wide, slow float upward, 4s):
Fantasy dreamscape. A child with flowing silver hair, translucent cloak, rides a giant luminous manta ray through a sky of floating jellyfish-islands. Each trails bioluminescent tendrils. Gradient sky shifts blue to gold.

Shot 2 (medium, gentle orbit, 3s):
The child touches a floating light orb, it bursts into golden sparks reforming into a tiny dancing fairy. Soft glow, magical particles.

Style: Fantasy dreamscape, surreal, bioluminescent particles, gradient colors, soft glow, ethereal floating.
Audio: Ethereal choir hum, wind chimes, sparkle bursts, soft wing whoosh.
```
